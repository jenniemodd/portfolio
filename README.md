# Inlämningsuppgift
Här är repot för din inlämningsuppgift.

Om filerna:
- `.gitignore` - Denna fil används för att ignorera/exkludera vissa systemfiler som inte behöver komma med i versionshanteringen. En sådan bör man alltid ha i sitt repo.
- `index.html` - För att sidan ska kunna publiceras automatiskt på GitHub Pages är det viktigt att filen heter `index.html` med ett litet `i` i början.
- I mappen `.github` finns ett script som automatiskt publicerar sidan till GitHub Pages.
- I mappen `.github` finns även instruktioner för hur CoPilot ska ge feedback på koden.
- Det går bra att redigera denna README-fil.


<h1>Välkommen till min Portfolio och allra första webbutvecklingsprojekt.</h1>

<p>Detta projekt är min personliga portfolio och min start på webbutvecklingens värld. Har tidigare ingen kod-erfarenhet så denna kommer definitivt förbättras under tidens gång. Portfolion är skapad i Visual Studio Code med fokus på grundläggande HTML-struktur och responsiv design med CSS.
Syftet med projektet är att visa att jag förstår webbsidans uppbyggnad, semantiska HTML-element och hur man skapar en användarvänlig layout som fungerar på olika skärmstorlekar.</p>

<h2>Innehåll & funktionalitet</h2>

<p>Portfolion uppfyller följande krav:
•	En bild med attribut och alt-text
•	En navigationsmeny som länkar till olika sektioner på samma sida
•	En huvudsektion (main) som innehåller sidans huvudsakliga innehåll
•	Tre projekt (två sedan innan och en ”dummie” enligt kravspecifikationen.
•	Ett sidofält (aside) med kompletterande information
•	Rubriker i minst tre nivåer (h1, h2, h3)
•	Minst en länk till en extern webbplats
•	Responsiv design som fungerar på mobil, surfplatta och desktop
•	Ett kontaktformulär med:
o	Namn
o	E-post
o	Webbplats
o	Telefonnummer
o	Dropdown-meny
o	Checkbox
o	Textfält (textarea)
o	Skicka-knapp (formuläret är inte kopplat till någon funktionalitet)
•	Kontaktuppgifter till mig
•	En sidfot (footer)
🛠️ Tekniker som används
•	HTML5
•	CSS3

(Ingen JavaScript används i detta projekt)</p>

<h3>Om projektet</h3>
<p>Detta är mitt allra första projekt inom webbutveckling och jag har ingen tidigare kod-erfarenhet. Fokus har därför legat på att lära mig grunderna ordentligt och bygga en stabil bas att utvecklas vidare från.</p>
